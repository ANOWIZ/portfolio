# Портфолио Михаила Колпакова

Портфолио для роли AI Generalist / AI Automation Specialist: проекты, опыт работы и контакты.

## Запуск

```powershell
npm.cmd install
npm.cmd run dev
```

## Проверка и сборка

```powershell
npm.cmd run build
```

## Публикация

Workflow `.github/workflows/deploy.yml` собирает сайт и публикует `dist` в GitHub Pages. В настройках репозитория нужно один раз выбрать **Settings → Pages → Source: GitHub Actions**.

Контактные данные и факты опыта взяты из резюме владельца. «Контур» и «Веха» — прототипы для возможного внедрения в компании; они не представлены как личные учебные проекты или завершённые внедрения. Публичные версии используют демонстрационные данные. Шрифт Onest с кириллицей включён в сборку; внешний сервис шрифтов не нужен. Основной текст — 18 px, подписи — от 15 px.

## Визуальное оформление

Референс — [goulash.tech](https://goulash.tech/): графитовые поверхности, белый текст, бирюзовые акценты и тонкие разделители. Логотип и изображения компании не используются; это личное портфолио кандидата. Анимации отключаются при `prefers-reduced-motion`. Адаптивность и основные переходы проверяются E2E-скриптом в соседнем репозитории Supplier Scout на ширинах 320, 390, 768, 1024 и 1440 px.
