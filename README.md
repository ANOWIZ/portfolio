# Портфолио Михаила Колпакова

Портфолио для роли AI Generalist / AI Automation Specialist: проекты, опыт работы и контакты.

## Запуск

```powershell
npm.cmd install
npm.cmd run dev
```

## Проверка и сборка

```powershell
npm.cmd run build
```

## Публикация

Workflow `.github/workflows/deploy.yml` собирает сайт и публикует `dist` в GitHub Pages. В настройках репозитория нужно один раз выбрать **Settings → Pages → Source: GitHub Actions**.

Контактные данные и факты опыта взяты из резюме владельца. Личные проекты отмечены как прототипы. Шрифт Golos Text с кириллицей включён в сборку; внешний сервис шрифтов не нужен. Основной текст — 18 px, подписи — от 15 px.
