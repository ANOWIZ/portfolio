# Портфолио Михаила Колпакова

Лендинг для роли AI Generalist / AI Automation Specialist: продуктовый профиль, проверяемые результаты и рабочие инженерные прототипы.

## Запуск

```powershell
npm.cmd install
npm.cmd run dev
```

## Проверка и сборка

```powershell
npm.cmd run build
```

## Публикация

Workflow `.github/workflows/deploy.yml` собирает сайт и публикует `dist` в GitHub Pages. В настройках репозитория нужно один раз выбрать **Settings → Pages → Source: GitHub Actions**.

Контактные данные и факты опыта взяты из резюме владельца. Метрики на странице относятся к разным проектам и не складываются в единый эффект.
